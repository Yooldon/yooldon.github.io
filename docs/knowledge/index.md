# 信息&知识

这一栏处理的是**信息怎么变成判断**：怎么记、记什么、什么时候删、怎么从一堆材料里抽出可用结论。

## 已经写了什么

- [像文档一样写笔记](/knowledge/method/note-structure) —— 三栏布局和四段式结构，以及它们为什么有效。
- [AI 时代该记什么](/knowledge/method/ai-era-notes) —— 一条判据、五类值得记的内容、AI 产出的处理规矩。

## 这一栏的判断标准

> 六个月后，这段内容我还能不能重新拿到？

能（网上有、AI 一秒生成）→ 只留指针。不能（当时的判断、现场的报错）→ 写全文。
