# 生活&兴趣

这一栏是**没有被任务驱动的那部分**：读的书、看的电影、去过的地方、突然冒出来的念头。

## 现在还是空的

空的没关系。宁可空着，也别为了填满而搬运——豆瓣和维基比我写得全，抄过来只是给搜索添噪音。

真开始写的时候，大概会是这些：

| 类型 | 记什么 | 不记什么 |
| --- | --- | --- |
| 读书 | 这本书改变了我哪个看法，具体到某一页 | 目录、金句摘抄 |
| 电影 | 看完之后我改变了什么判断 | 剧情简介、评分 |
| 旅行 | 具体的路线、踩到的坑、花了多少钱 | 攻略抄写 |
| 想法 | 当时为什么这么想，三个月后还成立吗 | 无来源的感慨 |

## 一条给自己的规矩

这里的每一篇，都该能回答一个问题：**它改变了我什么？**

答不上来的，删掉。
