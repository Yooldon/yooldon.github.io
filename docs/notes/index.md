# 笔记总览

左侧目录由目录结构自动生成：`docs/notes/<分类>/<slug>.md` 就是一篇笔记，不用改配置。

## 分类

| 分类 | 记什么 | 入口 |
| --- | --- | --- |
| 方法论 | 怎么写、怎么删、怎么判断该不该记 | [方法论](/notes/method/) |
| 工具 | 软件选型、站点搭建、工作流 | [工具](/notes/tools/) |
| 技术 | 具体 API、库、协议的使用与坑 | [技术](/notes/dev/) |

## 三类页面

这个站点只有三种笔记，写之前先想清楚是哪一类：

- **判例**（decision / failure）：我当时怎么判断的，结果如何。
- **参考**（reference）：可查的事实，压缩成表格和代码，标注出处与日期。
- **问题**（question）：还没想明白的，允许长期空着。

::: tip 一个判据
六个月后这段内容我还能不能重新拿到？能（网上有、AI 一秒生成）就只留链接；
不能（当时的判断、现场的报错）才写全文。
:::
