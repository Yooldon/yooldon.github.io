# 关于本站

这是 Yooldon 的个人知识库，用 [VitePress](https://vitepress.dev/) 构建，托管在 GitHub Pages。

## 这里放什么

只放三类东西：

| 类型 | 说明 |
| --- | --- |
| 判例 | 我做过什么判断，为什么，后来对不对 |
| 参考 | 可查的事实，压缩成表格，标注出处与日期 |
| 问题 | 还没想明白的，允许长期空着 |

不放：定义、教程、书摘、别人的观点摘录。那些问 AI 比翻我这儿快。

## 构建方式

```bash
pnpm install
pnpm dev      # 本地预览 http://localhost:5173
pnpm build    # 产物在 docs/.vitepress/dist
```

内容全部是 Markdown，可以直接被任何编辑器打开，也能整包喂给模型当上下文。
