# 快速开始

这一栏不讲知识，只讲**这个站怎么用**。看完这三节，你就能自己加笔记、改样式、发布上线。

## 四个分区

| 分区 | 放什么 | 现在有几篇 |
| --- | --- | --- |
| [快速开始](/start/) | 站点说明、写作流程、站点原理 | 2 |
| [信息&知识](/knowledge/) | 方法论、概念澄清、信息的筛选与加工 | 3 |
| [学习&工作](/work/) | 技术实践、踩坑记录、项目决策 | 2 |
| [生活&兴趣](/life/) | 读书、电影、旅行、随手想法 | 1 |

## 加一篇笔记

1. 在对应分区下新建 `.md`，文件名用英文 slug，例如 `knowledge/method/why-note.md`。
2. 写 frontmatter：`title` 必填，`date`、`order`、`type` 选填。
3. 正文按四段式：一句话定义 → 对照表 → 坑 → 我的判断。
4. 提交推送，一分钟自动上线。

**不用改配置**：左侧目录靠扫描目录生成，放进哪个文件夹就归到哪一类。

## 写作约定

::: tip 三条
- 能查到的内容只留链接，不留全文。
- 有对照关系就用表格，别写成三段散文。
- 每篇至少有一段「只有我能写」的内容。
:::

## 站点是怎么搭的

技术细节都在 [用 VitePress 搭知识站](/start/site)：三栏结构从哪来、侧栏怎么自动生成、Pages 怎么部署。

::: warning 一个坑
这个仓库的 Pages 构建源必须是 **GitHub Actions**。如果被改回「分支」，每次 push 都会触发 Jekyll
把 `main` 重新构建一遍，把 Actions 部署的产物覆盖掉，表现为整站 404。
:::
