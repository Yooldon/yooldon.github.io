# 学习&工作

这一栏是**动手的部分**：具体的工具、API、配置，以及踩过的坑。特点是保质期短，写的时候必须标日期和出处。

## 已经写了什么

- [DeepSeek 思考模式](/work/dev/deepseek-thinking-mode) —— 三种协议的参数对照、effort 映射表，以及什么场景该降档。

## 这一栏怎么写

| 要素 | 要求 |
| --- | --- |
| 事实 | 压缩成表格，标注抓取日期 |
| 现场 | 报错原文、错误假设、最后怎么定位的 |
| 判断 | 官方文档不写的那段：什么场景用哪个 |

::: warning 保质期
参考型内容三个月复查一次。表会变，判断通常还成立——所以「我的判断」那段最值得写。
:::
